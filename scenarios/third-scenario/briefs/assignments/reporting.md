# Assignment: audit report

Own `src/report.js` and `web/`.

Build an immutable report with total requested, allocated, and unserved litres,
plus copied allocation rows. The browser shell should show the synthetic nature
of the exercise, a labelled allocation table, a polite status region, visible
keyboard focus, responsive layout, and a reduced-motion rule.

The report explains a plan; it must not operate a device or contact a service.
