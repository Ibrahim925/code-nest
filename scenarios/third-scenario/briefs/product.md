# Greenhouse Scheduler

Finish a small offline planner for a fictional teaching greenhouse. It receives
synthetic sensor readings, calculates how much water each zone calls for, and
allocates a limited daily budget. The final report should make every decision
easy to inspect.

The repository already separates the work into four modules. Keep those
boundaries intact so validation, arithmetic, scheduling, and presentation can be
reviewed on their own. Run `npm test` to see the four unfinished areas.

This is a software exercise only. It does not connect to pumps, sensors, a
network, or real operating data.
