# Audit trail and map

Own `src/audit.js`, `src/map.js`, and the browser shell. Carry the credential path
into each immutable audit entry and make the map show the latest allowed, denied,
or unobserved state for every compartment. The same controller must drive both the
tests and the page.

Keep status readable without colour, preserve keyboard focus, and don't hide a
failed decision behind animation. The current damage-control plot is a starting
point, not permission to replace the simulator with browser-only state.
